## 👋 О себе

Иду в SRE осознанно: меньше ручной работы — больше автоматизации, воспроизводимости и надёжности.

- 🐧 **Linux** — рабочая среда: собственный сервер, Docker/Compose, bash, systemd, firewall, SSH.
- ⚙️ **Python** — от скриптов автоматизации до FastAPI-сервисов и desktop-приложений на PySide6.
- 🚀 **Строю [ClicKit](https://github.com/AkaDaka1/ClicKit)** — desktop-приложение с **274 автотестами**, CI/CD на GitHub Actions, Docker-образами и релизом 1.0.0.
- 📊 Сейчас добавляю сервисный слой: **FastAPI + PostgreSQL**, метрики, логи, трейсы, SLO, Terraform / k3s.
- 🎓 Преподавал IT-дисциплины ~2 года — умею объяснять сложное простыми словами.

Санкт-Петербург · офис / гибрид / удалёнка.

### 🖱️ ClicKit
Windows-приложение для автоматизации: сценарии собираются из **визуальных блоков**, без кода и без исполнения произвольного кода.

`Python 3.11+` `PySide6` `Blockly` `Docker` `GitHub Actions`

- 274 автотеста, ruff
- CI: линт, тесты 3.11–3.13, тест в Linux-контейнере, релиз по тегу
- Надёжность: аварийный стоп, валидируемый IR-формат, атомарные сохранения

[→ Репозиторий](https://github.com/AkaDaka1/ClicKit) · [→ Релиз 1.0.0](https://github.com/AkaDaka1/ClicKit/releases/latest)

### 🎭 Scenica
Информационная система управления театром: FastAPI + PostgreSQL API, desktop-клиент на PySide6, Android-клиент и интеграция с n8n.

`FastAPI` `PostgreSQL` `Docker Compose` `n8n` `pytest`

- 75+ автотестов на API и бизнес-логику
- Docker Compose dev/prod, конфиг через `.env`
- Развёртывание на собственном Linux-сервере

[→ Репозиторий](https://github.com/AkaDaka1/Scenica)
